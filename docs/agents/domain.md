# Domain documentation

ROMERO uses a single context. Before exploration, read the relevant sections of:

- `02-DOCS/wiki/sdd/constitution.md`: project constraints.
- `02-DOCS/wiki/sdd/decisions.md`: existing architecture and implementation decisions.
- The applicable spec and plan under `02-DOCS/wiki/sdd/`.
- `GLOSSARY.md` and `docs/adr/` if present. Create them lazily when new vocabulary or decisions need recording.

Use the established domain vocabulary in tickets, tests and reviews. Link existing decisions instead of copying them into a second decision register. Surface conflicts with an existing decision explicitly before changing it. The wiki index remains the project knowledge entry point.
