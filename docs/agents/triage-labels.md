# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Incoming report needs evaluation |
| needs-info | needs-info | Waiting for missing information |
| ready-for-agent | ready-for-agent | Specified for agent implementation; check blockers and rsc gates before starting |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Declined, with reason recorded before closing |

Use one readiness/triage role at a time. Preserve independent type labels such as bug or enhancement. Agent-generated tickets from an approved breakdown enter ready-for-agent; incoming raw requests enter needs-triage. Closing an issue does not by itself prove successful delivery.
